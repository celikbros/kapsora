# ADR-018: Özel entegratör adapter modeli; ilk adapter İşNet Nettefatura

- Durum: Accepted
- Tarih: 2026-09-02
- Karar sahipleri: İş sahibi (entegratör seçimi), Claude (tasarım)

## Bağlam

İş sahibi ilk e-Belge entegrasyonunun İşNet Nettefatura ile yapılmasını istedi; zamanla başka
entegratörler eklenecek. İşNet GİB özel entegratör listesindedir. Nettefatura web servis
sözleşmesi (WSDL/REST, metotlar, hata kodları, test ortamı) herkese açık değildir; başvuru ve
gizlilik sözleşmesi sonrası verilir. Dosya (Excel/text) aktarımı ve Luca konnektörleri de vardır.

## Karar

- Domain ve application katmanı yalnız `FiscalGateway` port'unu bilir: FetchInbox, GetStatus,
  SendResponse, SendDocument, LookupTaxpayer.
- Port GİB standardına göre tanımlanır: UBL-TR belge modeli, zarf/belge durumları, uygulama
  yanıtı, kayıtlı kullanıcı sorgusu. Entegratöre özgü uç noktalar ve kimlik doğrulama yalnız
  `internal/fiscal/infrastructure/integrator/<adapter>` paketinde kalır.
- İlk üretim adapter'ı `isnet_nettefatura`. Web servis erişimi gelene kadar: GİB standardından
  türetilmiş `mock` adapter (testler ve geliştirme) ve Nettefatura Excel şablonlarını okuyup
  yazan `file` adapter (geçici operasyon yolu).
- Adapter seçimi tenant başına `fiscal.integrator_account.adapter_code` ile yapılır.

## Sonuçlar

- İş sahibi I8 öncesi İşNet web servis başvurusu, gizlilik sözleşmesi ve test hesabı sağlar.
- Entegratör dokümanı gizlilik sözleşmesine göre `docs/integration/isnet/` veya ayrı özel depoda.
- İkinci entegratör eklemek yeni adapter paketi + consumer-driven contract testi demektir;
  domain değişmez.
- XML şema/schematron doğrulaması entegratörde kabul edilir; KAPSORA yapısal ve iş doğrulaması
  yapar, imza doğrulaması uyarı üreten kuraldır (bkz. ADR-020).
