# ADR-020: I0 araç ve sürüm sapmaları

- Durum: Accepted
- Tarih: 2026-09-02
- Karar sahipleri: İş sahibi (onay 02.09.2026), Claude

## Bağlam

v1.2 teknik sürüm baseline'ı (13.6) ve kütüphane seçimleri (14.1, 15.2) 08.08.2026 tarihlidir.
I0 başlarken bazı noktalar güncellenmeli veya v1.2'de boş bırakılan seçimler kapatılmalıydı.

## Kararlar

1. **Go 1.27.x** (v1.2: 1.26.5). Sıfırdan başlayan projede geçiş maliyeti yok; destek penceresi
   daha uzun; `encoding/json/v2` standart kütüphanede. go.mod `go 1.27.0`.
2. **Para hesapları** Go tarafında `shopspring/decimal`; DB'de `numeric(20,6)`. Float yok.
3. **XML doğrulama.** Go'da saf XSD/Schematron doğrulayıcı yok; cgo/libxml2 distroless imajla
   çelişir. Gelen belgede özel entegratörün GİB uyumlu doğrulamasına güvenilir; KAPSORA yapısal
   (encoding/xml tipli modeller) ve iş doğrulaması yapar; `goxmldsig` ile imza doğrulaması
   engelleyici değil uyarı üreten kuraldır. Belge düzenleme (MVP+1) geldiğinde xmllint tabanlı
   doğrulama servisi eklenir.
4. **Frontend API istemcisi** `openapi-typescript` + `openapi-fetch` ile üretilir.
5. **DB entegrasyon testleri** GitHub Actions PostgreSQL 18 servis konteyneri ve yerelde kurulu
   PostgreSQL ile `KAPSORA_TEST_ADMIN_DATABASE_URL` üzerinden çalışır. Testcontainers (v1.2 35.3)
   Docker gerektirir; Docker'sız geliştirici makinelerinde ve CI'da servis konteyneri daha
   basittir. Test her koşuda geçici veritabanı yaratır ve siler; gerçek migration'ları uygular.
6. **row_version ve updated_at DB tarafından yönetilir** (`platform.tg_touch_row`). Uygulama
   UPDATE'te bu kolonları yazmaz; yalnız WHERE'de `row_version` karşılaştırır (ETag/If-Match).
7. **Uygulama DB rolü** `kapsora_app`: LOGIN, NOBYPASSRLS, tablo sahibi değil; audit tablolarında
   UPDATE/DELETE hakkı yok. Rol oluşturma migration değil ortam işidir (compose init, runbook).
8. **Üretilen kod** (`api/generated`, `internal/platform/sqlcgen`) repoya commit edilir; CI
   yeniden üretip fark varsa başarısız olur.

## Sonuçlar

- v1.2 13.6 ve 14.1 tabloları bu ADR ile okunur; doküman metni değiştirilmez (dondurulmuş baseline).
- Yerel Windows makinede `-race` cgo ister; race testleri CI'da (Linux) çalışır.
